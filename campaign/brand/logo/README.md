# XAIHT Logo Suite

## Masters

- `xaiht-mark.svg`: full-color company mark.
- `xaiht-mark-mono.svg`: one-color mark using `currentColor`.
- `xaiht-wordmark.svg`: horizontal company signature on Obsidian.
- `xaiht-tlamatini-lockup.svg`: paired launch signature for XAIHT and Tlamatini.

## Construction

The mark is an `X` formed by crossing paths around an open central aperture. Maize represents human intent; Mineral Jade represents verified operation. Four small directional signals show that the operator can move across software, engines, devices, and workflows while the center remains open to inspection.

## Usage

- Keep clear space equal to the width of the central aperture.
- Do not rotate, skew, add glow, add a gradient, or place the mark on a noisy image without a solid field.
- Use the monochrome mark for one-color printing, embossing, engraving, and tiny UI placements.
- Do not use the full lockup below 240 px wide; use the company mark or wordmark instead.
- SVG files are the masters. PNG files are exports for convenience.
